# Security

The website is static and stores member details only in the visitor's own browser, but we still
take security and privacy seriously.

If you find a vulnerability or a privacy problem, **please do not open a public issue**.
Report it privately through GitHub: *Security → Report a vulnerability* on this repository.
We will reply as soon as we can and credit you if you wish.

Never commit secrets (API keys, tokens, passwords). Configuration that needs secrets lives in
the hosting provider or in GitHub encrypted secrets, never in the repository.
