# Roadmap

## V1 — Website and shareable cards (current)

- [x] Home, About, Privacy, Terms pages
- [x] English and Simplified Chinese, architecture ready for any language (incl. RTL)
- [x] Free joining with a nickname; random local member ID
- [x] Card studio: 3 templates, 5 sizes, PNG export, QR code
- [x] Self-chosen ways of living (10 presets + custom) and an optional time frame
- [x] Download, native share, copy share text, WeChat long-press path
- [ ] Final logo review and brand sign-off
- [ ] Custom domain and production deployment
- [ ] Real-device testing: iOS Safari, Android Chrome, WeChat, Instagram/X in-app browsers

## V1.x — Small improvements

- More languages: Spanish, French, Japanese, German, Portuguese (community translations)
- Traditional Chinese (`zh-Hant`)
- More card templates from community designers
- Optional privacy-friendly, cookie-free page statistics

## V2 — Personal habit journal (optional accounts)

- Optional accounts (e.g. Supabase / PostgreSQL), server-issued member IDs, online verification
- Private habit tracking: smoke-free / alcohol-free days, sleep, exercise; streaks; timeline
- Opt-in public profile page

## V3 — Open community

- Discussions and experience sharing, volunteers, translation and contributor programs, events

## V4 — Global organization

- Open governance, regional chapters, transparent finances, voluntary donations,
  evaluation of a formal legal entity
